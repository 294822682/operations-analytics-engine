# 经营趋势看板指标映射

本文件记录 N11-BI-QUARTER-TREND-CHART1 本次展示口径。既有核心 KPI 口径不改动；趋势图与月度对比仅用于 dashboard 展示。

## 数据源

- `output/fact_attribution.csv`：线索、账号、主播、成交、车型分区的事实表。
- `源文件/`、`历史文件/` 中 `总部新媒体线索*`：到店日期、意向车型等线索扩展字段。
- `源文件/`、`历史文件/` 中 `总部新媒体成交*`：成交车型与订单扩展字段，用于 EX7 分区复用。
- `源文件/`、`历史文件/` 中 `*直播进度表*`：开播账号、主播、消耗、曝光。
- `源文件/`、`历史文件/` 中 `*EXEED星途台账*`：种草账号与主播曝光。
- `config/monthly_targets.csv`：账号、主播月目标。
- `config/seed_monthly_targets.csv`：种草曝光月目标。
- `config/report_topline_config.json`：核心目标与 EX7 字段候选配置。

## BI 详细版合同边界

- `/dashboard/daily/latest/feishu-link` 是日报详细版 BI 入口，不是 dashboard source TSV 的技术预览页。
- 核心 KPI、账号、主播、种草与历史趋势优先复用 `feishu_dashboard_source_latest_*.tsv`，保证和日报总览一致。
- 到店数、到店率、到店成交率属于日报详细经营漏斗，来源为 `output/fact_attribution.csv` 中的线索归属与 `源文件/历史文件` 里的 `总部新媒体线索*` 到店日期字段；不得用无来源字段补 0。
- EX7 分组不进入当前 BI 页面/API 可见模块，除非后续重新确认业务需要。

## 边界处理

- 分母为 0 时返回空值，前端显示 `未提供` 或 `—`。
- 当分母存在且不为 0 时，转化率按公式如实展示。由于到店、成交可能来自历史线索或跨期归因，比例可能超过 100%，页面不做隐藏、不截断、不替换为异常提示。仅在分母为 0、分母缺失或源字段未接入时显示 `未提供` / `未接入`。
- 主播组别用于常态归属展示；大活动协作产生的线索、到店、成交按原始数据保留，不因线索组 / 种草组名称互助而改写事实。离职主播从当前 BI 可见聚合中隐藏，`桂婕` 固定保留在种草主播展示中、不进入主播表现模块，历史源数据不删除。
- 源字段缺失时返回 `未接入`，不补 0。
- 真实 0 保留为 0。
- 日期范围内没有某日数据时，趋势点保留 `null`，不自动补 0。
- 只有 `end_date` 时，`start_date` 默认取 `end_date` 所在月份往前推 2 个自然月的 1 日。
- 单次查询日期范围上限为 92 天。
- 当前查看范围为本期；上一周期按本期等长日期向前平移。
- 上一周期没有可用趋势点时显示 `上一周期数据不足`，不补 0，不生成假值。
- 所选范围超过 31 天时展示自然月月度对比。
- 月度 CPL = 月度费用 / 月度线索；月度 CPS = 月度费用 / 月度实销；分母为 0 或分母缺失时显示 `未提供`。
